# H2 真机遥控与遥测设计

上位机运行浏览器和 FastAPI。PC3 网关通过宇树 SDK2 和 CycloneDDS 对接 H2 高层运控，PC2 通过 RS-485 采集温湿度。遥控与遥测使用独立连接和工作线程。各端用本机单调时钟计时，设备间的系统时钟可以各自运行。

## 通道划分与调度

| 通道 | 上位机入口 | 上位机 → PC3 | PC3 处理 |
| --- | --- | --- | --- |
| 遥控 | WebSocket `/api/teleop/ws` | 独立 gRPC 客户端与 SSH 连接，`127.0.0.1:15052` → `127.0.0.1:50052` | 独立 gRPC 线程池，申请、方向、停步、心跳、释放以及申请前的轻量运控状态检查 |
| 状态 | HTTP `/api/robot` 等状态接口 | 独立 gRPC 客户端与 SSH 连接，`127.0.0.1:15051` → `127.0.0.1:50051` | 运控状态快照、PC2 温湿度和 BMS 电量 |

上位机为真机遥控保留专用工作线程。每个会话最多有一条遥控 RPC 正在执行，普通待发请求只保留最新一条。停步或释放会替换待发方向请求。被替换的请求按原序号返回 `superseded`，前端据此清理待回执记录。快速松手再按时，前端等上一条停步收到回执，再发送仍按住的方向。状态通道异常时，已建立的遥控会话继续由遥控通道和 PC3 的运控检查管理。

PC3 串行访问运控 SDK，按优先级处理等待请求。同一优先级按到达顺序处理。停步、释放和超时保护最高，其次是方向、心跳和临近过期的 FSM 刷新，普通状态查询与常规 FSM 轮询最后。状态查询先复制运控快照，释放 SDK 锁后再读温湿度和电量缓存。已开始的 SDK 调用会执行至返回或超时，随后才按优先级处理等待的请求。

## 遥控有效期与停步

1. 上位机浏览器和后端同机运行。后端用浏览器发帧时间检查 350 毫秒预算，收到后把剩余时间转为上位机单调时钟截止值。排队与等待工作线程都会消耗预算，发送 gRPC 时用当时剩余的时间作超时上限。
2. PC3 在成功回执中附本机单调时钟读数 `gateway_monotonic_ms`。上位机客户端记录该回执到达时刻。设 `G` 为 PC3 回执读数（毫秒），`R` 为上位机接收回执的单调时刻（纳秒），`D` 为上位机指令的单调截止值（纳秒），则指令中的 `gateway_deadline_ms = G + floor((D - R) / 1_000_000)`。回执传输耗时使换算偏保守，PC3 收到请求后继续用本机单调时钟扣除等待时间。
3. PC3 在进入 SDK 前校验控制权、严格递增的序号、RPC 是否仍有效及剩余预算。非零速度单帧最多 250 毫秒，剩余不足 40 毫秒的方向请求拒绝执行。有效的方向和心跳维持 2 秒租约。单帧到期发送零速度，整个会话仍按租约及 FSM 就绪状态判断。迟到的 SDK 运动回执触发零速度，网关返回 `stopped`，上位机保留会话。当前持权会话的合法停步不受方向指令截止时间限制。

浏览器会话断开时，上位机尝试释放控制权。若 PC3 联系不上，单帧和租约期限仍由 PC3 本机检查。租约到期或运控不再就绪时，网关撤销控制权，并在需要时请求零速度。若零速度未获应答，网关锁定故障并拒绝再次申请。停步成功回执表示运控收到并应答了零速度请求，实际停稳时间和距离由现场观察记录。

## 温湿度有效期

PC2 为传感器样本保留原始 `captured_at`（Unix 秒），生成由代理实例和样本序号组成的唯一 `sample_id`，用本机单调时钟计算 `age_seconds`。样本年龄达到 8 秒，代理返回不可用。PC3 用 `8 秒 - 采样年龄 - 本次 PC2 HTTP 请求往返耗时` 建立样本在 PC3 上的单调截止时间，状态响应带上原始采样时间、`environment_sample_id` 和 `environment_remaining_ms`。

上位机 gRPC 客户端和浏览器分别保守扣除对应的状态请求往返耗时。PC3 和浏览器都跟踪同一代理实例已接收的样本序号，同一样本的有效期只能持平或提前，已被新实例替代的代理实例不能重新覆盖读数。剩余时间用尽，或当前响应缺少有效的样本标识及剩余时间时，状态接口和界面按各自可用字段降级，页面清除读数和「实测」标记。`captured_at` 可用于对照现场采样记录，各端有效期独立于跨机系统时间差。

## 升级与验收

- 同时部署新版 PC2 代理、PC3 网关和上位机前后端。PC3 与上位机使用同一提交中的 gRPC 生成文件，停止旧进程再建立两条独立转发。旧版网关缺少单调时钟参考时，新版上位机关闭遥控会话。新版 PC3 拒绝缺少单调截止值的方向与心跳。旧版 PC2 缺少样本标识和采样年龄时，页面显示等待传感器数据。[现场联调与部署说明](H2_COMMISSIONING.md)
- 本机回环测试用 SDK 替身覆盖状态通道满载时的方向和停步、排队请求替换或过期、断开后释放，以及跨时钟基准和温湿度重复样本。现场无运动自检核对真机模式、申请、心跳和释放回执。实际遥控延迟、动作连续性、停稳距离和运动中断链单独记录现场结果。[回环集成测试](../tests/test_h2_hardware_end_to_end.py) · [网关时钟测试](tests/test_hardware_clock.py) · [温湿度测试](tests/test_hardware_environment.py)
