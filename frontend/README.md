# 巡检技术验证前端

Vue 3、TypeScript、Vite、Element Plus、Three.js、ECharts组成的本地验证界面。所有业务请求访问真实FastAPI接口，不直接连接机器人网关。页面始终标明模拟机器人和合成数据。

在本目录执行：

```bash
pnpm install
pnpm dev
```

默认访问 `http://127.0.0.1:5173`，`/api`代理至 `http://127.0.0.1:8000`。使用 `pnpm typecheck` 检查类型，`pnpm build` 生成生产静态文件。运行时要求Node.js 24 LTS。

依赖以`pnpm-lock.yaml`锁定。`pnpm-workspace.yaml`只允许esbuild执行安装构建脚本。

默认三点路线下发后，通过每秒轮询获取机器人和任务真实反馈。任务完成或停止后可保存人工复核意见并生成PDF、Excel、JSON报告。请求超时时保留下发请求标识，重试沿用原标识以配合后端幂等约束。

在“手动遥控”面板申请模拟控制权后，按住方向按钮或在面板内按住方向键；松开或点击“停步”立即发送停步请求。切换窗口、隐藏页面、关闭页面或释放控制权会结束会话，恢复页面后需重新申请。遥控与巡检互斥，三维场景显示模拟器返回的位置和朝向。

本页面属于本机技术验证，生产身份认证和用户权限尚未纳入本轮验证。三维机柜为程序生成的示意模型，照片是网关生成的合成证据，不代表真实现场。
