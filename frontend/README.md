# 巡检技术验证前端

使用 Vue 3、TypeScript、Vite、Element Plus、Three.js 和 ECharts 的本地验证界面。业务请求通过 FastAPI 访问机器人网关。完整启动步骤见[项目说明](../README.md)。

在本目录执行：

```bash
pnpm install --frozen-lockfile
pnpm dev
```

默认访问 `http://127.0.0.1:5173`，`/api` 代理至 `http://127.0.0.1:8000`。使用 `pnpm typecheck` 检查类型，`pnpm build` 生成生产静态文件。运行时要求 Node.js 24.12 或同系列更高版本。

依赖以 `pnpm-lock.yaml` 锁定。`pnpm-workspace.yaml` 只允许 esbuild 执行安装构建脚本。

## 模拟巡检

默认显示「巡检技术验证台」，并标注「模拟机器人 · 合成数据」。下发三点路线后，页面轮询机器人状态和任务进度，展示模拟位姿、温湿度、合成图片及环境采样趋势。任务完成或停止后，可保存人工复核意见并生成 PDF、Excel 和 JSON 报告。请求超时时保留下发请求标识，重试沿用原标识。

页面收到 `/api/health` 的真机模式确认后才显示链路管理并开始轮询现场链路状态。模拟页面通过 `/api/robot` 获取本机模拟网关的状态。

在「手动遥控」面板申请控制权后，按住方向按钮或在面板内按住方向键，松开或点击「停步」即发送停步请求。切换窗口、隐藏页面、关闭页面或释放控制权会结束会话，恢复页面后需重新申请。遥控与巡检互斥。

## H2 真机遥控

真机模式显示「H2 真机遥控验证台」，提供机器人连接、高层运动服务、机器人电量、环境温湿度和手动遥控面板。高层运动服务就绪后可申请控制权。页面显示的是运动或停步请求的应答，实际动作和停稳仍需现场确认。巡检任务、模拟三维场景、人工复核和报告入口只在模拟模式显示。

环境卡片读取 `/api/robot` 的 `temperature_c`、`humidity_percent`、`environment_sample_id` 和 `environment_remaining_ms`。页面按剩余有效时间在本机单调计时，温湿度从 PC2 采样起最多显示 8 秒。重复轮询同一采样不会延长有效期。`environment_captured_at` 保留 PC2 的原始 Unix 采样时间，供排查使用。连接断开，或读数、样本标识或剩余有效时间缺失或无效时，卡片显示「—」和「等待传感器数据」。缺失的机器人电量显示「—」。

「地图显示」和「图像显示」目前预留位置，分别等待现场地图和相机画面接入。本地演示可以使用标注为示例的静态地图和图片。当前改动已在本地模拟及演示数据下验证，真机动作、现场传感器和相机尚未实测。现场流程见 [H2 真机遥控现场联调](../robot-gateway/H2_COMMISSIONING.md)。
